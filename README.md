# StudioMargin-Claude

Foglio Excel gratuito per freelance e piccoli studi: tariffa oraria sostenibile, preventivi con margini,
previsione di cassa a 12 mesi, cruscotto e preventivo stampabile. **Versione 0.1 — in validazione, nessuna vendita attiva.**

- `StudioMargin.xlsx` — il prodotto (dati dimostrativi da sostituire).
- `index.html` — pagina del sito (GitHub Pages) con schermate reali in `img/`.
- `tools/build_studiomargin.py` — genera il file da zero (`python tools/build_studiomargin.py`).
- `tests/test_studiomargin.py` — suite di 50 controlli contro un modello indipendente; esiti in `tests/RISULTATI.txt`.
- `sfida/Sfida_1Euro_Ledger.xlsx` — ledger e scacchiera della sfida «1 € → 64 raddoppi».

Limiti: non calcola imposte, contributi, IVA a debito o insoluti; non è consulenza fiscale. Collaudato con LibreOffice; verifica con Excel da eseguire.
